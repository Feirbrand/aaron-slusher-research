# Cross-Substrate

This folder holds objects whose defining job is crossing between substrates — human/practitioner and technical/AI — rather than sitting at one level of the primary NFA stack.

**New folder, built Aug 19 2026 — no prior version existed.** `architecture/` has its own object-class index; this folder didn't, and needed one for the same reason: land here with no orientation otherwise.

## Why these objects aren't under `architecture/`

Everything in `architecture/` occupies one position in a linear stack — Neuroformation explains formation, the Grid locates it, NAM transmits through it, and so on. The objects here don't work that way. Their job is the crossing itself, which makes them adjacent to the stack, not another rung in it. See `architecture/README.md`'s object-class table for how this folder's members are classified relative to everything else.

## What's here

| Object | What it does | Status |
|---|---|---|
| [TTT](ttt/) | Converts practitioner pattern intelligence into technical/system architecture | Public |
| UNICA | Cross-substrate thesis — staged public, not yet built | Staged |

## Relationship to `architecture/`

Both TTT and UNICA are NFA-family by architecture and identity — see [Neural Formation Architecture](../architecture/neural-formation-architecture/) for how they connect to the rest of the stack. Filing them here instead of inside `architecture/` is a statement about their function, not a demotion.
