# Architecture

This folder contains the public architecture layer for Aaron M. Slusher's research — the object-class map for Neural Formation Architecture and its components.

**Migrated from `methods/` — Aug 18 2026.** `methods/` treated a methodology, a coordinate framework, a transmission protocol, a process, a developmental system, and an output state as if they were the same kind of object. They are not. This folder classifies each one by what it actually is.

## Object Classes

No license, no affiliation, no DOI in this table — that's a different axis, tracked per-work in [PUBLICATIONS.md](../PUBLICATIONS.md).

| Object | Class |
|---|---|
| [Neural Formation Architecture](neural-formation-architecture/) | Architecture container |
| [Neuroformation™](neuroformation/) | Governing methodology |
| [Elevation Grid™](elevation-grid/) | Coordinate framework |
| [Neural Access Method™](neural-access-method/) | Transmission protocol |
| [The Parate Process™](parate-process/) | Pathway-clearing method |
| [Ground. Ascent. Altitude.™](ground-ascent-altitude/) | Developmental system |
| [Adapted Architecture](adapted-architecture/) | Governing design principle + output state |
| [TTT](../cross-substrate/ttt/) | Bridge / transduction |

**On TTT's placement:** filed in `cross-substrate/`, not here, because its functional job crosses substrates rather than sitting at one level of this stack. A reverse-direction extension exists in research but is unapproved — not canon, not reflected in the class label above.

**How the jobs sequence.** Parate clears the pathway. NAM transmits through it. GAA builds what has to hold. Neuroformation explains why any of it works. The Grid says where you are while it happens. TTT converts what NAM opened into technical architecture once the rest of the stack has run.

## What Lives Here

Each folder contains a public orientation README that describes the object at the conceptual level, links to the canonical paper (where it exists), and points to the DOI record.

Full implementation details, private protocols, and operational guides remain outside this repository.

## DOI Gate Rule

A folder links to published materials once the paper is on Zenodo with a permanent DOI. Until then, the folder holds a placeholder README only. Overview pages may exist before DOI release when they describe the public stack.
